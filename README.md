# Proyecto-CO3321
Proyecto de análisis de datos para la materia de Estadística para Ingenieros CO3321 en la Universidad Simón Bolívar.

# Ejecución
Requieres:
- Tener R instalado en tu computadora: https://cran.r-project.org/bin/windows/base/
- Instalar las extensiones de:
    - R
    - R Syntax

    ambas de REditorSupport

- Para ejecutar, simplemente resaltar una sección de código y presionar Ctrl + Enter
